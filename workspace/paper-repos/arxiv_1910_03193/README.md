# DeepONet: Learning nonlinear operators for identifying differential equations based on the universal approximation theorem of operators

**Paper:** Lu Lu, Pengzhan Jin, and George Em Karniadakis (2019; journal version in Nature Machine Intelligence, 2021), [arXiv:1910.03193](https://arxiv.org/abs/1910.03193).
**Code:** independent PyTorch reproduction written from the paper. This is not the authors' repository and does not claim access to their original run logs or checkpoints.

> **Contribution note.** The scaffold in this directory (model, data pipeline, training/evaluation code, tests, configs, SIR) was generated by an AI assistant and committed under a bot identity so that machine-written work is clearly flagged. Paper-scale experiment runs and results are to be added by the assigned human contributor in their own commits.

## Reproduction status

This repository implements GRF input-function sampling, reference solvers for the antiderivative, nonlinear ODE, and gravity-pendulum operators, stacked/unstacked DeepONet (with bias), the FNN baseline, training with MSE, and test-MSE evaluation.

**The paper-scale experiments have not been run here.** The authoring workspace is CPU-only (2 cores, ~1 GB RAM). The unit tests and the smoke configuration verify code paths and invariants, not the paper's empirical claims. Do not report smoke metrics as reproduction results. Paper-scale runs need: a CPU or single GPU; the full antiderivative protocol takes on the order of tens of minutes to hours depending on hardware.

## What the paper does

DeepONet represents an operator G with two networks: a branch net that sees the input function u through its values at m fixed sensors, and a trunk net that sees the query location y. The prediction is the inner product of their p-dimensional outputs plus a bias. The paper motivates this from the universal approximation theorem for operators, compares stacked vs unstacked branches, and benchmarks against FNN, ResNet, and seq2seq on ODE and PDE operators with inputs drawn from Gaussian random fields.

## Model and training defaults

- **Sensors:** m=100 equispaced points on [0, 1].
- **GRF:** RBF kernel, length scale l=0.2.
- **Model:** unstacked DeepONet, p=40, ReLU; stacked variant and FNN baseline also trained.
- **Optimizer:** Adam, lr 1e-3, MSE loss, full batch.

## Important assumptions and limits

- Use p=40, branch hidden [40], trunk hidden [40, 40] with ReLU.
- 10,000 training (u, y) pairs with one output location per function; 1,000 test functions x 100 locations.
- 50,000 full-batch Adam steps at lr 1e-3.
- Pendulum operator integrated on T=1 using RK4 on a 1,001-point grid.
- The diffusion-reaction PDE example is not implemented in this scaffold.

## Install

Python 3.10+ is required. For CPU-only PyTorch install the CPU wheel first; then install the project and tests:

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install torch --index-url https://download.pytorch.org/whl/cpu
python -m pip install -e '.[test]'
pytest -q
```

For CUDA, install the PyTorch build matching your driver, then `python -m pip install -e '.[test]'`.

## Paper-scale protocol

```bash
PYTHONPATH=src python -m deeponet_repro train --config configs/paper.json --output-root results/runs
```

Choose the operator with `data.operator` (`antiderivative`, `nonlinear_ode`, `pendulum`). Each entry in `models` is trained and evaluated on the same data. Runs with `--steps` are truncated and must not be reported as the paper protocol.
