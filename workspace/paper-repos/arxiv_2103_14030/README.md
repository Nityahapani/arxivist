# Swin Transformer: Hierarchical Vision Transformer using Shifted Windows

**Paper:** Ze Liu, Yutong Lin, Yue Cao, Han Hu, Yixuan Wei, Zheng Zhang, Stephen Lin, and Baining Guo (2021), [arXiv:2103.14030](https://arxiv.org/abs/2103.14030).
**Code:** independent PyTorch reproduction written from the paper, with the authors' public [`microsoft/Swin-Transformer`](https://github.com/microsoft/Swin-Transformer) consulted only for the shifted-window mask construction. This is not the authors' repository and does not claim access to their original run logs or checkpoints.

> **Contribution note.** The scaffold in this directory (model, data pipeline, training/evaluation code, tests, configs, SIR) was generated by an AI assistant and committed under a bot identity so that machine-written work is clearly flagged. Paper-scale experiment runs and results are to be added by the assigned human contributor in their own commits.

## Reproduction status

This repository implements window partition/reverse, window attention with relative position bias, shifted windows via cyclic shift and attention masking, patch merging, Swin-T/S/B/L configurations (Swin-T parameter count verified at 28.3M), stochastic depth, and the AdamW/cosine/Mixup/CutMix recipe.

**The paper-scale experiments have not been run here.** The authoring workspace is CPU-only (2 cores, ~1 GB RAM). The unit tests and the smoke configuration verify code paths and invariants, not the paper's empirical claims. Do not report smoke metrics as reproduction results. Paper-scale runs need: 8–16 GPUs for several days for Swin-T ImageNet-1K training, plus an ImageNet copy.

## What the paper does

Swin computes self-attention inside non-overlapping M×M windows, so cost grows linearly with image size. Every second block shifts the window grid by M/2 so information flows across windows; the shift is implemented with a cyclic roll and a mask that blocks attention between tokens from different original regions. Patch-merging layers halve resolution and double channels, producing a hierarchical backbone usable for classification, detection, and segmentation.

## Model and training defaults

- **Model:** Swin-T, window 7, drop path 0.2.
- **Optimizer:** AdamW lr 1e-3 (batch 1024), weight decay 0.05, cosine, 20 warm-up epochs, 300 epochs.
- **Regularisation:** Mixup/CutMix, label smoothing 0.1.

## Important assumptions and limits

- RandAugment and Random Erasing are not implemented; Mixup/CutMix/label smoothing are.
- If a stage's resolution is <= window size, the window equals the full map and no shift is applied.
- Clip-norm 5.0 from the reference recipe is documented but not applied in the scaffold loop.

See [`sir.json`](../../sir-registry/arxiv_2103_14030/sir.json) and the [architecture plan](../../sir-registry/arxiv_2103_14030/architecture_plan_summary.md) for structured assumptions and confidence annotations, and [`comparison/`](comparison/) for the paper-vs-reproduction table.

## Install

Python 3.10+ is required. For CPU-only PyTorch install the CPU wheel first; then install the project and tests:

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install torch --index-url https://download.pytorch.org/whl/cpu
python -m pip install -e '.[test]'
pytest -q
```

For CUDA, install the PyTorch build matching your driver, then `python -m pip install -e '.[test]'`.


## Paper-scale protocol

```bash
PYTHONPATH=src python -m swin_repro train --config configs/paper.json --output-root results/runs
```

Requires an ImageNet-1K loader and multi-GPU launcher. Runs with `--steps` are truncated and must not be reported.
