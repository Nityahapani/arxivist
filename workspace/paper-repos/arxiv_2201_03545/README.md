# A ConvNet for the 2020s

**Paper:** Zhuang Liu, Hanzi Mao, Chao-Yuan Wu, Christoph Feichtenhofer, Trevor Darrell, and Saining Xie (2022), [arXiv:2201.03545](https://arxiv.org/abs/2201.03545).
**Code:** independent PyTorch reproduction written from the paper, with the authors' public [`facebookresearch/ConvNeXt`](https://github.com/facebookresearch/ConvNeXt) consulted only for initialisation details. This is not the authors' repository and does not claim access to their original run logs or checkpoints.

> **Contribution note.** The scaffold in this directory (model, data pipeline, training/evaluation code, tests, configs, SIR) was generated by an AI assistant and committed under a bot identity so that machine-written work is clearly flagged. Paper-scale experiment runs and results are to be added by the assigned human contributor in their own commits.

## Reproduction status

This repository implements the ConvNeXt block, patchify stem, LN downsampling layers, T/S/B/L/XL configurations (parameter counts verified against Table 1 for T and S), linearly increasing stochastic depth, layer scale, Mixup/CutMix with label smoothing, AdamW + warmup/cosine, and EMA.

**The paper-scale experiments have not been run here.** The authoring workspace is CPU-only (2 cores, ~1 GB RAM). The unit tests and the smoke configuration verify code paths and invariants, not the paper's empirical claims. Do not report smoke metrics as reproduction results. Paper-scale runs need: 8 × A100 (or equivalent) for several days for ConvNeXt-T 300-epoch ImageNet-1K training, plus an ImageNet copy.

## What the paper does

Starting from ResNet-50, the authors apply a sequence of changes inspired by vision Transformers: a better training recipe, stage ratios (3,3,9,3), a 4×4 patchify stem, depthwise convolutions with wider channels, inverted bottlenecks, 7×7 kernels, GELU, fewer activations/norms, LayerNorm instead of BatchNorm, and separate downsampling layers. The result, ConvNeXt, matches or beats Swin Transformers at similar FLOPs.

## Model and training defaults

- **Model:** ConvNeXt-T, stochastic depth 0.1, layer scale 1e-6.
- **Optimizer:** AdamW lr 4e-3 (batch 4096), weight decay 0.05, cosine with 20 warm-up epochs, 300 epochs.
- **Regularisation:** Mixup 0.8, CutMix 1.0, label smoothing 0.1, EMA 0.9999.

## Important assumptions and limits

- RandAugment and Random Erasing are not implemented in the scaffold; Mixup/CutMix/label smoothing are.
- EMA of weights (decay 0.9999) is optional and evaluated separately.
- An ImageNet loader must be supplied.

See [`sir.json`](../../sir-registry/arxiv_2201_03545/sir.json) and the [architecture plan](../../sir-registry/arxiv_2201_03545/architecture_plan_summary.md) for structured assumptions and confidence annotations, and [`comparison/`](comparison/) for the paper-vs-reproduction table.

## Install

Python 3.10+ is required. For CPU-only PyTorch install the CPU wheel first; then install the project and tests:

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install torch --index-url https://download.pytorch.org/whl/cpu
python -m pip install -e '.[test]'
pytest -q
```

For CUDA, install the PyTorch build matching your driver, then `python -m pip install -e '.[test]'`.

## Quick smoke test

A deliberately tiny configuration that checks the pipeline end to end; it is **not** a paper result.

```bash
PYTHONPATH=src python -m convnext_repro smoke --config configs/smoke.json --output-root results/smoke
```

## Paper-scale protocol

```bash
PYTHONPATH=src python -m convnext_repro train --config configs/paper.json --output-root results/runs
```

Requires an ImageNet-1K loader and a multi-GPU launcher. Runs with `--steps` are truncated and must not be reported.
