# Reproduction outputs

Paper-scale metrics, checkpoints, and figures are written here when commands in the top-level README are run.

- `runs/` contains one directory per seed/split with exact run config, split metadata, metrics CSV, and summary JSON.
- `figures/` contains plots aggregated from completed suites.
- `smoke/` is reserved for the short pipeline check; smoke outputs are not paper results.

Large paper-scale runs and checkpoints are git-ignored. The current repository adds no synthetic or fabricated paper-result metrics; full-scale runs were not performed in the authoring environment.
