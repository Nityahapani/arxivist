# LoRA: Low-Rank Adaptation of Large Language Models

**Paper:** Edward J. Hu, Yelong Shen, Phillip Wallis, Zeyuan Allen-Zhu, Yuanzhi Li, Shean Wang, Lu Wang, and Weizhu Chen (2021), [arXiv:2106.09685](https://arxiv.org/abs/2106.09685).
**Code:** independent PyTorch reproduction written from the paper, with the authors' public [`microsoft/LoRA`](https://github.com/microsoft/LoRA) (`loralib`) consulted only for implementation conventions. This is not the authors' repository and does not claim access to their original run logs or checkpoints.

> **Contribution note.** The scaffold in this directory (model, data pipeline, training/evaluation code, tests, configs, SIR) was generated by an AI assistant and committed under a bot identity so that machine-written work is clearly flagged. Paper-scale experiment runs and results are to be added by the assigned human contributor in their own commits.

## Reproduction status

This repository implements the LoRA layer (`LoRALinear`), injection into named projections (W_q/W_v), freezing utilities, weight merging for zero-latency inference, LoRA-only checkpoints, a small Transformer for CPU checks, and the RoBERTa-base GLUE protocol (Table 2) on Hugging Face `transformers`.

**The paper-scale experiments have not been run here.** The authoring workspace is CPU-only (2 cores, ~1 GB RAM). The unit tests and the smoke configuration verify code paths and invariants, not the paper's empirical claims. Do not report smoke metrics as reproduction results. Paper-scale runs need: one CUDA GPU (>=16 GB) per GLUE task for RoBERTa-base, the optional `[hf]` dependencies, and network access to download `roberta-base` and GLUE.

## What the paper does

LoRA freezes the pretrained weights W0 and learns a low-rank update ΔW = BA (A: r×k, B: d×r) for selected projection matrices, scaled by α/r. B starts at zero, so training begins from the pretrained function. After training, BA can be added into W0, so inference costs nothing extra. The paper evaluates LoRA on RoBERTa/DeBERTa (GLUE), GPT-2 (E2E, WebNLG, DART) and GPT-3 175B (WikiSQL, MNLI, SAMSum), and studies which matrices to adapt and how small r can be.

## Model and training defaults

- **LoRA:** r=8, α=8 (scaling α/r = 1), applied to `query` and `value` projections of every RoBERTa layer.
- **Init:** A ~ N(0, (1/r)²), B = 0; `init='kaiming'` matches the released `loralib`.
- **Optimizer:** AdamW with linear decay and 6% warmup; per-task batch size / epochs / LR in `configs/paper.json`.
- **Trainable:** LoRA matrices + classification head; 5 seeds, report median.

## Important assumptions and limits

- Initialise A from N(0, (1/r)^2) and B to zero; kaiming-uniform (loralib default) available via init='kaiming'.
- Use the RoBERTa-base per-task batch size / epochs / learning rate transcribed into configs/paper.json from the appendix table; contributors should verify each value against the paper.
- Train the task classifier head together with LoRA matrices; all other weights frozen.
- CPU smoke test uses a synthetic pretrain -> adapt task with a 2-layer, width-32 model; it validates mechanics only.

See [`sir.json`](../../sir-registry/arxiv_2106_09685/sir.json) and the [architecture plan](../../sir-registry/arxiv_2106_09685/architecture_plan_summary.md) for structured assumptions and confidence annotations, and [`comparison/`](comparison/) for the paper-vs-reproduction table.

## Install

Python 3.10+ is required. For CPU-only PyTorch install the CPU wheel first; then install the project and tests:

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install torch --index-url https://download.pytorch.org/whl/cpu
python -m pip install -e '.[test]'
pytest -q
```

For CUDA, install the PyTorch build matching your driver, then `python -m pip install -e '.[test]'`.

For the paper-scale GLUE protocol also install `python -m pip install -e '.[hf]'`.

## Quick smoke test

A deliberately tiny configuration that checks the pipeline end to end; it is **not** a paper result.

```bash
PYTHONPATH=src python -m lora_repro smoke --config configs/smoke.json --output-root results/smoke
```

## Paper-scale protocol

```bash
PYTHONPATH=src python -m lora_repro train --config configs/paper.json --output-root results/runs
```

Select the GLUE task with the `task` field (mnli, sst2, mrpc, cola, qnli, qqp, rte, stsb) and run once per seed (`--seed`). Any run with `--steps` is truncated and must not be reported as the paper protocol.
