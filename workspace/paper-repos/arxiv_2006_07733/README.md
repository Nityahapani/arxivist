# Bootstrap Your Own Latent: A New Approach to Self-Supervised Learning

**Paper:** Jean-Bastien Grill, Florian Strub, Florent Altché, Corentin Tallec, Pierre H. Richemond, Elena Buchatskaya, Carl Doersch, Bernardo Avila Pires, Zhaohan Daniel Guo, Mohammad Gheshlaghi Azar, Bilal Piot, Koray Kavukcuoglu, Rémi Munos, and Michal Valko (2020), [arXiv:2006.07733](https://arxiv.org/abs/2006.07733).
**Code:** independent PyTorch reproduction written from the paper. This is not the authors' repository and does not claim access to their original run logs or checkpoints.

> **Contribution note.** The scaffold in this directory (model, data pipeline, training/evaluation code, tests, configs, SIR) was generated by an AI assistant and committed under a bot identity so that machine-written work is clearly flagged. Paper-scale experiment runs and results are to be added by the assigned human contributor in their own commits.

## Reproduction status

This repository implements the online/target networks with projector and predictor MLPs, the symmetrised normalised-MSE loss, the EMA target update with cosine τ schedule, BYOL's asymmetric augmentation pipeline (blur 1.0/0.1, solarize 0.0/0.2), LARS with warmup-cosine, and a linear evaluation probe.

**The paper-scale experiments have not been run here.** The authoring workspace is CPU-only (2 cores, ~1 GB RAM). The unit tests and the smoke configuration verify code paths and invariants, not the paper's empirical claims. Do not report smoke metrics as reproduction results. Paper-scale runs need: a multi-node GPU or TPU cluster for 1000 ImageNet epochs at batch 4096 (paper: 512 TPU v3 cores, ~8 h).

## What the paper does

BYOL trains an online network (encoder, projector, predictor) to regress the target network's projection of a differently augmented view. The target is an exponential moving average of the online encoder and projector and receives no gradients. Without negative pairs, BYOL matches or beats contrastive methods on ImageNet linear evaluation.

## Model and training defaults

- **Encoder:** ResNet-50; projector / predictor 4096→256 with BN.
- **Optimizer:** LARS, LR 0.2 × batch/256, weight decay 1.5e-6 (biases and BN excluded), cosine with 10-epoch warmup.
- **Target:** τ_base 0.996 → 1 (cosine).

## Important assumptions and limits

- BatchNorm running statistics of the target network are copied from the online network.
- Short SGD linear probe on frozen features in smoke runs.
- Not included; synthetic data and CIFAR-10 only.

See [`sir.json`](../../sir-registry/arxiv_2006_07733/sir.json) and the [architecture plan](../../sir-registry/arxiv_2006_07733/architecture_plan_summary.md) for structured assumptions and confidence annotations, and [`comparison/`](comparison/) for the paper-vs-reproduction table.

## Install

Python 3.10+ is required. For CPU-only PyTorch install the CPU wheel first; then install the project and tests:

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install torch --index-url https://download.pytorch.org/whl/cpu
python -m pip install -e '.[test]'
pytest -q
```

For CUDA, install the PyTorch build matching your driver, then `python -m pip install -e '.[test]'`.

## Quick smoke test

A deliberately tiny configuration that checks the pipeline end to end; it is **not** a paper result.

```bash
PYTHONPATH=src python -m byol_repro smoke --config configs/smoke.json --output-root results/smoke
```

## Paper-scale protocol

```bash
PYTHONPATH=src python -m byol_repro train --config configs/paper.json --output-root results/runs
```

Requires an ImageNet streaming loader and large batch training. Runs with `--steps` are truncated and must not be reported.
