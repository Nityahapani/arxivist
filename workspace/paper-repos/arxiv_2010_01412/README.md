# Sharpness-Aware Minimization for Efficiently Improving Generalization

**Paper:** Pierre Foret, Ariel Kleiner, Hossein Mobahi, and Behnam Neyshabur (2020), [arXiv:2010.01412](https://arxiv.org/abs/2010.01412).
**Code:** independent PyTorch reproduction written from the paper. This is not the authors' repository and does not claim access to their original run logs or checkpoints.

> **Contribution note.** The scaffold in this directory (model, data pipeline, training/evaluation code, tests, configs, SIR) was generated by an AI assistant and committed under a bot identity so that machine-written work is clearly flagged. Paper-scale experiment runs and results are to be added by the assigned human contributor in their own commits.

## Reproduction status

This repository implements the SAM optimizer wrapper (ascent step to w+ε̂ with ε̂=ρ·g/‖g‖₂, restore, base-optimizer descent with the perturbed gradient), m-sharpness via per-chunk perturbations, WideResNet-28-10, CIFAR augmentation, cosine-LR training, and the matched SGD baseline.

**The paper-scale experiments have not been run here.** The authoring workspace is CPU-only (2 cores, ~1 GB RAM). The unit tests and the smoke configuration verify code paths and invariants, not the paper's empirical claims. Do not report smoke metrics as reproduction results. Paper-scale runs need: one modern GPU for ~1 day per WRN-28-10 200-epoch run (SAM ≈ 2× SGD cost); run SAM and SGD for comparison.

## What the paper does

SAM replaces the loss L(w) with the worst-case loss in a ρ-ball around w. A first-order approximation gives a closed-form perturbation ε̂ = ρ·∇L/‖∇L‖; the update uses the gradient at w+ε̂. Each step therefore costs two forward/backward passes. The paper reports consistent test-error reductions on CIFAR-10/100 and ImageNet, robustness to label noise, and introduces m-sharpness.

## Model and training defaults

- **Model:** WRN-28-10.
- **SAM:** ρ=0.05, p=2.
- **Base optimizer:** SGD momentum 0.9, cosine LR from 0.1, weight decay 5e-4.
- **Budget:** 200 epochs, batch 256.

## Important assumptions and limits

- Batch 256, LR 0.1 cosine, weight decay 5e-4, 200 epochs, rho 0.05.
- Emulate the paper's data-parallel m-sharpness by splitting each batch into chunks of m=128 with independent perturbations.
- Only the basic augmentation row (crop+flip) is implemented; Cutout and AutoAugment rows are not.
- No numeric targets are recorded in the SIR; read the target error rates from Table 1 when filling in results.

See [`sir.json`](../../sir-registry/arxiv_2010_01412/sir.json) and the [architecture plan](../../sir-registry/arxiv_2010_01412/architecture_plan_summary.md) for structured assumptions and confidence annotations, and [`comparison/`](comparison/) for the paper-vs-reproduction table.

## Install

Python 3.10+ is required. For CPU-only PyTorch install the CPU wheel first; then install the project and tests:

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install torch --index-url https://download.pytorch.org/whl/cpu
python -m pip install -e '.[test]'
pytest -q
```

For CUDA, install the PyTorch build matching your driver, then `python -m pip install -e '.[test]'`.

For CIFAR also install `python -m pip install -e '.[vision]'`.

## Quick smoke test

A deliberately tiny configuration that checks the pipeline end to end; it is **not** a paper result.

```bash
PYTHONPATH=src python -m sam_repro smoke --config configs/smoke.json --output-root results/smoke
```

## Paper-scale protocol

```bash
PYTHONPATH=src python -m sam_repro train --config configs/paper.json --output-root results/runs
```

Run once with `train.optimizer = sam` and once with `sgd` on identical settings and seeds, then compare test error. Runs with `--steps` are truncated and must not be reported.
