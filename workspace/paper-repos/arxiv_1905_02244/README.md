# Searching for MobileNetV3

**Paper:** Andrew Howard, Mark Sandler, Grace Chu, Liang-Chieh Chen, Bo Chen, Mingxing Tan, Weijun Wang, Yukun Zhu, Ruoming Pang, Vijay Vasudevan, Quoc V. Le, and Hartwig Adam (2019), [arXiv:1905.02244](https://arxiv.org/abs/1905.02244).
**Code:** independent PyTorch reproduction written from the paper. This is not the authors' repository and does not claim access to their original run logs or checkpoints.

> **Contribution note.** The scaffold in this directory (model, data pipeline, training/evaluation code, tests, configs, SIR) was generated by an AI assistant and committed under a bot identity so that machine-written work is clearly flagged. Paper-scale experiment runs and results are to be added by the assigned human contributor in their own commits.

## Reproduction status

This repository implements h-swish / hard-sigmoid, SE with hard-sigmoid gating, the bneck block, MobileNetV3-Large and -Small per Tables 1–2 with the efficient last stage (parameter counts verified: 5.4M / 2.5M), width multipliers, and an RMSProp + step-decay + EMA training loop.

**The paper-scale experiments have not been run here.** The authoring workspace is CPU-only (2 cores, ~1 GB RAM). The unit tests and the smoke configuration verify code paths and invariants, not the paper's empirical claims. Do not report smoke metrics as reproduction results. Paper-scale runs need: 8 × modern GPUs for several days (large batch RMSProp), plus an ImageNet copy.

## What the paper does

MobileNetV3 combines platform-aware NAS (block-level) and NetAdapt (layer-level) searches with hand-designed changes: a cheaper last stage that pools before the final 1×1 expansion, an expensive-to-cheap stem reduction to 16 filters, h-swish in deeper layers, and SE modules gated by hard-sigmoid. Two models are released (Large and Small) and also used for detection (SSDLite) and segmentation (LR-ASPP).

## Model and training defaults

- **Model:** MobileNetV3-Large 1.0 at 224 px.
- **Optimizer:** RMSProp momentum 0.9, LR 0.1 at batch 4096, weight decay 1e-5.
- **EMA:** 0.9999; dropout 0.2 before the classifier.

## Important assumptions and limits

- Interpret 'learning rate decay rate of 0.01 every 3 epochs' as multiplying LR by 0.97 every 3 epochs.
- Interpret 'dropout of 0.8' as keep-probability 0.8 (dropout rate 0.2) before the classifier.
- Use eps=0.0316 (≈ sqrt(1e-3)) to mimic TensorFlow's epsilon placement.
- ~600 epochs (187,500 steps at batch 4096).

See [`sir.json`](../../sir-registry/arxiv_1905_02244/sir.json) and the [architecture plan](../../sir-registry/arxiv_1905_02244/architecture_plan_summary.md) for structured assumptions and confidence annotations, and [`comparison/`](comparison/) for the paper-vs-reproduction table.

## Install

Python 3.10+ is required. For CPU-only PyTorch install the CPU wheel first; then install the project and tests:

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install torch --index-url https://download.pytorch.org/whl/cpu
python -m pip install -e '.[test]'
pytest -q
```

For CUDA, install the PyTorch build matching your driver, then `python -m pip install -e '.[test]'`.

## Quick smoke test

A deliberately tiny configuration that checks the pipeline end to end; it is **not** a paper result.

```bash
PYTHONPATH=src python -m mobilenetv3_repro smoke --config configs/smoke.json --output-root results/smoke
```

## Paper-scale protocol

```bash
PYTHONPATH=src python -m mobilenetv3_repro train --config configs/paper.json --output-root results/runs
```

Set `model.mode` to `large` or `small`. Requires an ImageNet loader. Runs with `--steps` are truncated and must not be reported.

```text
configs/paper.json                    # paper-scale protocol
```
