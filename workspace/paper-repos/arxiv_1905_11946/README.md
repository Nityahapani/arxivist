# EfficientNet: Rethinking Model Scaling for Convolutional Neural Networks

**Paper:** Mingxing Tan and Quoc V. Le (2019), [arXiv:1905.11946](https://arxiv.org/abs/1905.11946).
**Code:** independent PyTorch reproduction written from the paper. This is not the authors' repository and does not claim access to their original run logs or checkpoints.

> **Contribution note.** The scaffold in this directory (model, data pipeline, training/evaluation code, tests, configs, SIR) was generated by an AI assistant and committed under a bot identity so that machine-written work is clearly flagged. Paper-scale experiment runs and results are to be added by the assigned human contributor in their own commits.

## Reproduction status

This repository implements MBConv blocks with squeeze-and-excitation and drop connect, the B0 baseline table, compound scaling (α=1.2, β=1.1, γ=1.15) with channel/repeat rounding, B0–B7 configurations (parameter counts verified for B0, B1, B3), and the RMSProp / exponential-decay training loop.

**The paper-scale experiments have not been run here.** The authoring workspace is CPU-only (2 cores, ~1 GB RAM). The unit tests and the smoke configuration verify code paths and invariants, not the paper's empirical claims. Do not report smoke metrics as reproduction results. Paper-scale runs need: a multi-GPU node (8 × A100) for several days for B0, much more for B7; plus an ImageNet copy.

## What the paper does

Scaling a ConvNet along one dimension (depth, width, or input resolution) quickly saturates. The paper proposes compound scaling: choose α, β, γ by a small grid search under α·β²·γ² ≈ 2 and scale depth by α^φ, width by β^φ, and resolution by γ^φ. Applied to a NAS-found baseline (B0) this gives B1–B7, which are more accurate and efficient than prior ConvNets.

## Model and training defaults

- **Model:** EfficientNet-B0 at 224 px, dropout 0.2, drop connect 0.2.
- **Optimizer:** RMSProp (decay 0.9, momentum 0.9, ε=1e-3), LR 0.256 (batch 4096) × 0.97 every 2.4 epochs, weight decay 1e-5.
- **BN momentum:** 0.99 (PyTorch 0.01).

## Important assumptions and limits

- Batch 4096 and 350 epochs from the authors' public TPU recipe.
- Label smoothing 0.1 (public recipe).
- AutoAugment and weight EMA are not implemented in the scaffold.
- SE squeezes to 0.25 x block input channels.

See [`sir.json`](../../sir-registry/arxiv_1905_11946/sir.json) and the [architecture plan](../../sir-registry/arxiv_1905_11946/architecture_plan_summary.md) for structured assumptions and confidence annotations, and [`comparison/`](comparison/) for the paper-vs-reproduction table.

## Install

Python 3.10+ is required. For CPU-only PyTorch install the CPU wheel first; then install the project and tests:

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install torch --index-url https://download.pytorch.org/whl/cpu
python -m pip install -e '.[test]'
pytest -q
```

For CUDA, install the PyTorch build matching your driver, then `python -m pip install -e '.[test]'`.

## Quick smoke test

A deliberately tiny configuration that checks the pipeline end to end; it is **not** a paper result.

```bash
PYTHONPATH=src python -m efficientnet_repro smoke --config configs/smoke.json --output-root results/smoke
```

## Paper-scale protocol

```bash
PYTHONPATH=src python -m efficientnet_repro train --config configs/paper.json --output-root results/runs
```

Set `model.name` to b0…b7 and `data.image_size` to the matching resolution (224…600). Requires an ImageNet loader. Runs with `--steps` are truncated and must not be reported.

## Layout

```text
configs/paper.json                    # paper-scale protocol
```
