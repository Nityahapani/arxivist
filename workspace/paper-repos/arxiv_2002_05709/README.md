# A Simple Framework for Contrastive Learning of Visual Representations

**Paper:** Ting Chen, Simon Kornblith, Mohammad Norouzi, and Geoffrey Hinton (2020), [arXiv:2002.05709](https://arxiv.org/abs/2002.05709).
**Code:** independent PyTorch reproduction written from the paper, with the authors' public [`google-research/simclr`](https://github.com/google-research/simclr) consulted only for augmentation conventions. This is not the authors' repository and does not claim access to their original run logs or checkpoints.

> **Contribution note.** The scaffold in this directory (model, data pipeline, training/evaluation code, tests, configs, SIR) was generated by an AI assistant and committed under a bot identity so that machine-written work is clearly flagged. Paper-scale experiment runs and results are to be added by the assigned human contributor in their own commits.

## Reproduction status

This repository implements the SimCLR augmentation pipeline on tensors (crop, flip, colour jitter, grayscale, blur), ResNet-18/50 encoders with CIFAR/ImageNet stems and width multipliers, the 2-layer projection head, NT-Xent, LARS with warmup + cosine schedule, and linear evaluation.

**The paper-scale experiments have not been run here.** The authoring workspace is CPU-only (2 cores, ~1 GB RAM). The unit tests and the smoke configuration verify code paths and invariants, not the paper's empirical claims. Do not report smoke metrics as reproduction results. Paper-scale runs need: 1-8 GPUs for CIFAR-10 (ResNet-50, batch 1,024, ~1,000 epochs); a TPU/GPU cluster for ImageNet.

## What the paper does

Each image in a batch is augmented twice; the two views are encoded by a ResNet into h and projected by an MLP into z. NT-Xent treats the other view of the same image as the positive and the other 2(N−1) views in the batch as negatives. After pretraining the head is discarded and a linear classifier is trained on frozen h. The paper ablates augmentations, the projection head, batch size, training length, and temperature.

## Model and training defaults

- **Encoder:** ResNet-50 (CIFAR stem for 32×32 inputs).
- **Head:** Linear(2048,2048)-ReLU-Linear(2048,128).
- **Loss:** NT-Xent, τ=0.5 (CIFAR) / 0.1 (ImageNet).
- **Optimizer:** LARS, LR = 0.3×batch/256, weight decay 1e-6, warmup then cosine decay.

## Important assumptions and limits

- Run the CIFAR-10 variant (ResNet-50, CIFAR stem, no blur, batch 1024, tau 0.5, colour strength 0.5, ~1000 epochs) as the primary reproducible target.
- Linear evaluation uses Nesterov-momentum SGD on frozen, pre-extracted features without augmentation.
- Colour jitter is implemented in-tensor (brightness/contrast/saturation 0.8s, hue 0.2s, random order).
- LARS with trust coefficient 0.001, momentum 0.9; 1-D parameters (bias, BN) excluded from adaptation and weight decay.

See [`sir.json`](../../sir-registry/arxiv_2002_05709/sir.json) and the [architecture plan](../../sir-registry/arxiv_2002_05709/architecture_plan_summary.md) for structured assumptions and confidence annotations, and [`comparison/`](comparison/) for the paper-vs-reproduction table.

## Install

Python 3.10+ is required. For CPU-only PyTorch install the CPU wheel first; then install the project and tests:

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install torch --index-url https://download.pytorch.org/whl/cpu
python -m pip install -e '.[test]'
pytest -q
```

For CUDA, install the PyTorch build matching your driver, then `python -m pip install -e '.[test]'`.

For CIFAR-10 also install `python -m pip install -e '.[vision]'`.

## Quick smoke test

A deliberately tiny configuration that checks the pipeline end to end; it is **not** a paper result.

```bash
PYTHONPATH=src python -m simclr_repro smoke --config configs/smoke.json --output-root results/smoke
```

## Paper-scale protocol

```bash
PYTHONPATH=src python -m simclr_repro train --config configs/paper.json --output-root results/runs
```

The default config is the CIFAR-10 setting. Change `train.batch_size`, `train.steps`, and `train.temperature` to reproduce the Appendix B.9 sweep. Runs with `--steps` are truncated and must not be reported as paper results.
