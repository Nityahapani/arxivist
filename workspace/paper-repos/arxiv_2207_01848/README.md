# TabPFN: A Transformer That Solves Small Tabular Classification Problems in a Second

**Paper:** Noah Hollmann, Samuel Müller, Katharina Eggensperger, and Frank Hutter (2022), [arXiv:2207.01848](https://arxiv.org/abs/2207.01848).
**Code:** independent PyTorch reproduction written from the paper. This is not the authors' repository and does not claim access to their original run logs or checkpoints.

> **Contribution note.** The scaffold in this directory (model, data pipeline, training/evaluation code, tests, configs, SIR) was generated by an AI assistant and committed under a bot identity so that machine-written work is clearly flagged. Paper-scale experiment runs and results are to be added by the assigned human contributor in their own commits.

## Reproduction status

This repository implements a synthetic SCM/BNN prior sampler, feature normalisation and padding, the PFN Transformer with the train/test attention mask (test predictions independent of each other and of training-set order), prior fitting with random train/test split positions, ensemble prediction with feature and class permutations, and zero-shot evaluation against logistic regression on a real dataset.

**The paper-scale experiments have not been run here.** The authoring workspace is CPU-only (2 cores, ~1 GB RAM). The unit tests and the smoke configuration verify code paths and invariants, not the paper's empirical claims. Do not report smoke metrics as reproduction results. Paper-scale runs need: 8 GPUs for ~20 h of prior fitting; inference runs on CPU.

## What the paper does

A PFN is trained once, offline, on millions of synthetic classification datasets: for each, part of the samples (with labels) form the context and the rest are queries whose labels must be predicted. At test time a new dataset is passed in a single forward pass, so 'training' is in-context inference that approximates the Bayesian posterior predictive under the prior.

## Model and training defaults

- **Model:** 12 layers, d=512, 4 heads, FFN 1024.
- **Limits:** ≤1000 samples, ≤100 features, ≤10 classes.

## Important assumptions and limits

- A simplified SCM/BNN mixture (random MLP structure, random activations, node noise, quantile thresholds) without feature warping, categorical features or missing values.
- Adam with warmup-cosine; steps, batch and LR are assumptions.
- Feature-permutation and class-relabelling ensemble; power transforms are omitted.
- Smoke evaluation on sklearn's breast cancer dataset instead of OpenML-CC18.

See [`sir.json`](../../sir-registry/arxiv_2207_01848/sir.json) and the [architecture plan](../../sir-registry/arxiv_2207_01848/architecture_plan_summary.md) for structured assumptions and confidence annotations, and [`comparison/`](comparison/) for the paper-vs-reproduction table.

## Install

Python 3.10+ is required. For CPU-only PyTorch install the CPU wheel first; then install the project and tests:

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install torch --index-url https://download.pytorch.org/whl/cpu
python -m pip install -e '.[test]'
pytest -q
```

For CUDA, install the PyTorch build matching your driver, then `python -m pip install -e '.[test]'`.

## Quick smoke test

```bash
PYTHONPATH=src python -m tabpfn_repro smoke --config configs/smoke.json --output-root results/smoke
```

## Paper-scale protocol

```bash
PYTHONPATH=src python -m tabpfn_repro train --config configs/paper.json --output-root results/runs
```

Prior fitting at paper scale takes ~20 GPU-days-equivalent; evaluation needs OpenML-CC18 (`pip install .[openml]`). Runs with `--steps` are truncated and must not be reported.
