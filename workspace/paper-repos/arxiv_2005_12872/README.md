# End-to-End Object Detection with Transformers

**Paper:** Nicolas Carion, Francisco Massa, Gabriel Synnaeve, Nicolas Usunier, Alexander Kirillov, and Sergey Zagoruyko (2020), [arXiv:2005.12872](https://arxiv.org/abs/2005.12872).
**Code:** independent PyTorch reproduction written from the paper. This is not the authors' repository and does not claim access to their original run logs or checkpoints.

> **Contribution note.** The scaffold in this directory (model, data pipeline, training/evaluation code, tests, configs, SIR) was generated by an AI assistant and committed under a bot identity so that machine-written work is clearly flagged. Paper-scale experiment runs and results are to be added by the assigned human contributor in their own commits.

## Reproduction status

This repository implements DETR end to end: ResNet backbone with frozen BatchNorm, 2D sine positional encodings, the post-norm transformer encoder/decoder with positional encodings added at every layer, 100 learned object queries, class and 3-layer box heads, Hungarian matching (verified optimal by brute force), the set criterion with no-object weight 0.1, L1 5 and GIoU 2, auxiliary losses at every decoder layer, and the AdamW / gradient clipping / step-LR training recipe. The R50 model has the paper's 41M parameters.

**The paper-scale experiments have not been run here.** The authoring workspace is CPU-only (2 cores, ~1 GB RAM). The unit tests and the smoke configuration verify code paths and invariants, not the paper's empirical claims. Do not report smoke metrics as reproduction results. Paper-scale runs need: 16 × V100-class GPUs for ~3–5 days (300–500 epochs) plus COCO 2017.

## What the paper does

DETR passes CNN features with positional encodings through a transformer encoder; a decoder turns a fixed set of learned object queries into N predictions in parallel. Training matches predictions to ground truth one-to-one with the Hungarian algorithm and applies classification and box (L1 + GIoU) losses on the matched pairs, so duplicates are penalised and NMS is unnecessary.

## Model and training defaults

- **Model:** d=256, 8 heads, 6+6 layers, FFN 2048, dropout 0.1, 100 queries.
- **Loss:** CE (no-object 0.1), L1 5, GIoU 2; aux losses.
- **Optimizer:** AdamW, LR 1e-4 / backbone 1e-5, wd 1e-4, clip 0.1.

## Important assumptions and limits

- Backbone is randomly initialised here; paper uses ImageNet-pretrained ResNet.
- Synthetic coloured rectangles in smoke runs; COCO loader and augmentations not included.
- Epochs converted to iterations with ~1848 iterations/epoch at batch 64.

See [`sir.json`](../../sir-registry/arxiv_2005_12872/sir.json) and the [architecture plan](../../sir-registry/arxiv_2005_12872/architecture_plan_summary.md) for structured assumptions and confidence annotations, and [`comparison/`](comparison/) for the paper-vs-reproduction table.

## Install

Python 3.10+ is required. For CPU-only PyTorch install the CPU wheel first; then install the project and tests:

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install torch --index-url https://download.pytorch.org/whl/cpu
python -m pip install -e '.[test]'
pytest -q
```

For CUDA, install the PyTorch build matching your driver, then `python -m pip install -e '.[test]'`.

## Quick smoke test

A deliberately tiny configuration that checks the pipeline end to end; it is **not** a paper result.

```bash
PYTHONPATH=src python -m detr_repro smoke --config configs/smoke.json --output-root results/smoke
```

## Paper-scale protocol

```bash
PYTHONPATH=src python -m detr_repro train --config configs/paper.json --output-root results/runs
```

Needs a COCO loader with DETR augmentations and an ImageNet-pretrained ResNet-50 (`pip install .[coco]`). Runs with `--steps` are truncated and must not be reported.
