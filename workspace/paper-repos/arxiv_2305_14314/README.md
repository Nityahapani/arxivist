# QLoRA: Efficient Finetuning of Quantized LLMs

**Paper:** Tim Dettmers, Artidoro Pagnoni, Ari Holtzman, and Luke Zettlemoyer (2023), [arXiv:2305.14314](https://arxiv.org/abs/2305.14314).
**Code:** independent PyTorch reproduction written from the paper. This is not the authors' repository and does not claim access to their original run logs or checkpoints.

> **Contribution note.** The scaffold in this directory (model, data pipeline, training/evaluation code, tests, configs, SIR) was generated by an AI assistant and committed under a bot identity so that machine-written work is clearly flagged. Paper-scale experiment runs and results are to be added by the assigned human contributor in their own commits.

## Reproduction status

This repository implements the NF4 data type (verified against the published 16-level table), FP4 and Int4 baselines, blockwise absmax quantization, Double Quantization with the 0.127 bits/parameter overhead, an NF4 linear layer with on-the-fly dequantization, QLoRA adapters on all linear layers, and a toy pretrain → quantize → adapter-finetune pipeline with the paper's optimiser settings.

**The paper-scale experiments have not been run here.** The authoring workspace is CPU-only (2 cores, ~1 GB RAM). The unit tests and the smoke configuration verify code paths and invariants, not the paper's empirical claims. Do not report smoke metrics as reproduction results. Paper-scale runs need: a single 48GB GPU for 65B models (smaller GPUs for 7B–33B); the reference pipeline runs on CPU.

## What the paper does

QLoRA stores the pretrained weights in a 4-bit NormalFloat format whose levels are quantiles of a standard normal, quantized in blocks of 64 with a per-block absmax constant that is itself quantized to 8 bits. During finetuning the weights are dequantized to bf16 on the fly and only low-rank adapters on every linear layer are trained, with paged optimizers absorbing memory spikes.

## Model and training defaults

- **Quantization:** NF4, block 64, double quantization block 256.
- **LoRA:** r=64, α=16, dropout 0.1, all linear layers.
- **Optimizer:** Adam, LR 2e-4 constant, batch 16, max grad norm 0.3.

## Important assumptions and limits

- Asymmetric quantile construction with offset 0.9677083 (8 positive, 7 negative levels plus exact zero), matching the published NF4 table.
- Second-level constants are 8-bit symmetric integers per 256-block (centred by the mean).
- Not implemented (CPU reference); standard Adam is used.
- A tiny GPT pretrained in-script stands in for LLaMA.

## Install

Python 3.10+ is required. For CPU-only PyTorch install the CPU wheel first; then install the project and tests:

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install torch --index-url https://download.pytorch.org/whl/cpu
python -m pip install -e '.[test]'
pytest -q
```

For CUDA, install the PyTorch build matching your driver, then `python -m pip install -e '.[test]'`.

## Paper-scale protocol

```bash
PYTHONPATH=src python -m qlora_repro train --config configs/paper.json --output-root results/runs
```

Paper-scale runs need LLaMA weights, bitsandbytes, PEFT and a GPU (`pip install .[hf]`). Runs with `--steps` are truncated and must not be reported.
