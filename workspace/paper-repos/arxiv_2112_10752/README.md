# High-Resolution Image Synthesis with Latent Diffusion Models

**Paper:** Robin Rombach, Andreas Blattmann, Dominik Lorenz, Patrick Esser, and Björn Ommer (2022), [arXiv:2112.10752](https://arxiv.org/abs/2112.10752).
**Code:** independent PyTorch reproduction written from the paper. This is not the authors' repository and does not claim access to their original run logs or checkpoints.

> **Contribution note.** The scaffold in this directory (model, data pipeline, training/evaluation code, tests, configs, SIR) was generated by an AI assistant and committed under a bot identity so that machine-written work is clearly flagged. Paper-scale experiment runs and results are to be added by the assigned human contributor in their own commits.

## Reproduction status

This repository implements both first-stage autoencoders (KL with diagonal-Gaussian posterior and VQ with straight-through quantisation), a PatchGAN discriminator with hinge loss, the time-conditional UNet with SpatialTransformer cross-attention, class and text conditioning encoders, the ε-prediction latent diffusion objective with a scaled-linear schedule, DDIM sampling, classifier-free guidance with label dropout, latent rescaling, and a two-stage training pipeline.

**The paper-scale experiments have not been run here.** The authoring workspace is CPU-only (2 cores, ~1 GB RAM). The unit tests and the smoke configuration verify code paths and invariants, not the paper's empirical claims. Do not report smoke metrics as reproduction results. Paper-scale runs need: one or more A100 GPUs for several days per model, plus the dataset (ImageNet / LAION / CelebA-HQ).

## What the paper does

LDMs first train an autoencoder that compresses images by a factor f into a latent space that is perceptually equivalent but much smaller. A diffusion model is then trained in that latent space with a UNet whose intermediate layers attend to a conditioning sequence through cross-attention. Sampling runs the reverse diffusion in latent space and decodes once, cutting compute by orders of magnitude versus pixel-space diffusion.

## Model and training defaults

- **Autoencoder:** KL-reg weight 1e-6, Adam (0.5, 0.9), LR 4.5e-6, discriminator after warmup.
- **Diffusion:** T = 1000, ε-prediction, AdamW LR 1e-4.
- **Sampling:** DDIM, η = 0; classifier-free guidance with 10% label dropout.

## Important assumptions and limits

- LPIPS is not implemented (needs pretrained VGG weights); first stage uses L1 + KL + PatchGAN.
- 'Scaled linear' β schedule 0.00085 → 0.012 with T = 1000 (as in the released LDM configs).
- Channel multipliers, attention resolutions and iteration counts in configs/paper.json are best-recalled values.
- Latents are rescaled by 1/std estimated on the training set before diffusion (KL models).

See [`sir.json`](../../sir-registry/arxiv_2112_10752/sir.json) and the [architecture plan](../../sir-registry/arxiv_2112_10752/architecture_plan_summary.md) for structured assumptions and confidence annotations, and [`comparison/`](comparison/) for the paper-vs-reproduction table.

## Install

Python 3.10+ is required. For CPU-only PyTorch install the CPU wheel first; then install the project and tests:

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install torch --index-url https://download.pytorch.org/whl/cpu
python -m pip install -e '.[test]'
pytest -q
```

For CUDA, install the PyTorch build matching your driver, then `python -m pip install -e '.[test]'`.

## Quick smoke test

A deliberately tiny configuration that checks the pipeline end to end; it is **not** a paper result.

```bash
PYTHONPATH=src python -m ldm_repro smoke --config configs/smoke.json --output-root results/smoke
```

## Paper-scale protocol

```bash
PYTHONPATH=src python -m ldm_repro train --config configs/paper.json --output-root results/runs
```

Needs dataset loaders, LPIPS/FID tooling (`pip install .[metrics]`) and GPUs. Runs with `--steps` are truncated and must not be reported.
