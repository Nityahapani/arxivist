# Segment Anything

**Paper:** Alexander Kirillov, Eric Mintun, Nikhila Ravi, Hanzi Mao, Chloe Rolland, Laura Gustafson, Tete Xiao, Spencer Whitehead, Alexander C. Berg, Wan-Yen Lo, Piotr Dollár, and Ross Girshick (2023), [arXiv:2304.02643](https://arxiv.org/abs/2304.02643).
**Code:** independent PyTorch reproduction written from the paper. This is not the authors' repository and does not claim access to their original run logs or checkpoints.

> **Contribution note.** The scaffold in this directory (model, data pipeline, training/evaluation code, tests, configs, SIR) was generated by an AI assistant and committed under a bot identity so that machine-written work is clearly flagged. Paper-scale experiment runs and results are to be added by the assigned human contributor in their own commits.

## Reproduction status

This repository implements the windowed-attention ViT image encoder with global blocks and neck, the random-Fourier prompt encoder for points, boxes and masks, the two-way transformer mask decoder with multimask and single-mask outputs and IoU head, the 20:1 focal plus dice loss with minimum-over-masks, IoU MSE, interactive training with corrective point sampling and mask feedback, and a synthetic-shape training pipeline.

**The paper-scale experiments have not been run here.** The authoring workspace is CPU-only (2 cores, ~1 GB RAM). The unit tests and the smoke configuration verify code paths and invariants, not the paper's empirical claims. Do not report smoke metrics as reproduction results. Paper-scale runs need: many A100 GPUs for days, the SA-1B dataset, and an MAE-pretrained ViT-H.

## What the paper does

SAM computes an image embedding once with a large ViT, then answers any number of prompts with a light decoder. Sparse prompts become tokens with Fourier positional encodings, dense mask prompts are added to the embedding, and a two-way transformer updates both tokens and image features. Output mask tokens act as dynamic linear classifiers over the upscaled embedding, and an IoU token scores each mask.

## Model and training defaults

- **Decoder:** 2 layers, dim 256, 8 heads, MLP 2048, 4 mask tokens.
- **Loss:** focal:dice 20:1, IoU MSE, minimum over 3 masks.
- **Interaction:** 11 rounds per mask (paper); corrective points from the error region.

## Important assumptions and limits

- AdamW lr 8e-4, warmup 250, 90k iterations, batch 256, weight decay 0.1, step decay, drop path 0.4, layer decay 0.8 (configs/paper.json).
- Multiple masks only on the first round when no box is given; otherwise the single-mask token.
- No relative positional embeddings in windowed attention; random init instead of MAE pretraining.
- Text-prompt (CLIP) experiments are not implemented.

## Install

Python 3.10+ is required. For CPU-only PyTorch install the CPU wheel first; then install the project and tests:

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install torch --index-url https://download.pytorch.org/whl/cpu
python -m pip install -e '.[test]'
pytest -q
```

For CUDA, install the PyTorch build matching your driver, then `python -m pip install -e '.[test]'`.

## Quick smoke test

A deliberately tiny configuration that checks the pipeline end to end; it is **not** a paper result.

```bash
PYTHONPATH=src python -m segment_anything_repro smoke --config configs/smoke.json --output-root results/smoke
```

## Paper-scale protocol

```bash
PYTHONPATH=src python -m segment_anything_repro train --config configs/paper.json --output-root results/runs
```

Requires SA-1B, an MAE-pretrained ViT-H and a multi-GPU cluster. Truncated runs must not be reported.
