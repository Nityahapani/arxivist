# Retentive Network: A Successor to Transformer for Large Language Models

**Paper:** Yutao Sun, Li Dong, Shaohan Huang, Shuming Ma, Yuqing Xia, Jilong Xue, Jianyong Wang, and Furu Wei (2023), [arXiv:2307.08621](https://arxiv.org/abs/2307.08621).
**Code:** independent PyTorch reproduction written from the paper. This is not the authors' repository and does not claim access to their original run logs or checkpoints.

> **Contribution note.** The scaffold in this directory (model, data pipeline, training/evaluation code, tests, configs, SIR) was generated by an AI assistant and committed under a bot identity so that machine-written work is clearly flagged. Paper-scale experiment runs and results are to be added by the assigned human contributor in their own commits.

## Reproduction status

This repository implements retention in parallel, recurrent, and chunkwise forms (exact equivalence verified in float64, including the cross-chunk state), multi-scale per-head decays, the gated multi-scale retention block with GroupNorm, a RetNet LM with O(1)-state recurrent decoding that matches parallel logits token by token, and a toy decoding-cost benchmark.

**The paper-scale experiments have not been run here.** The authoring workspace is CPU-only (2 cores, ~1 GB RAM). The unit tests and the smoke configuration verify code paths and invariants, not the paper's empirical claims. Do not report smoke metrics as reproduction results. Paper-scale runs need: hundreds of GPUs for the 1.3B–6.7B scaling experiments; equivalence tests run on CPU.

## What the paper does

Retention replaces softmax attention with a decayed linear recurrence: each head maintains a d_k×d_v state that decays by γ and accumulates k·vᵀ. Unrolling gives a parallel form with a causal decay mask D, and a hybrid chunkwise form processes chunks in parallel while passing a recurrent state between them. Different heads use different γ, and outputs are group-normalised and gated with swish.

## Model and training defaults

- **Heads:** γ_i = 1 − 2^(−5−i); value/gate dim 2d.
- **Optimizer:** AdamW (0.9, 0.98), wd 0.05.

## Important assumptions and limits

- The paper's three retention normalisations (QK^T/sqrt(d), decay-matrix normalisation, score normalisation) are reduced to key scaling d^-1/2; GroupNorm's scale invariance makes the others numerically, not functionally, relevant.
- xPos-style Θ is implemented as RoPE without the xPos length-extrapolation scaling.
- AdamW (0.9, 0.98), wd 0.05, LR 6e-4, warmup 375, 25k steps for 1.3B.

See [`sir.json`](../../sir-registry/arxiv_2307_08621/sir.json) and the [architecture plan](../../sir-registry/arxiv_2307_08621/architecture_plan_summary.md) for structured assumptions and confidence annotations, and [`comparison/`](comparison/) for the paper-vs-reproduction table.

## Install

Python 3.10+ is required. For CPU-only PyTorch install the CPU wheel first; then install the project and tests:

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install torch --index-url https://download.pytorch.org/whl/cpu
python -m pip install -e '.[test]'
pytest -q
```

For CUDA, install the PyTorch build matching your driver, then `python -m pip install -e '.[test]'`.

## Quick smoke test

A deliberately tiny configuration that checks the pipeline end to end; it is **not** a paper result.

```bash
PYTHONPATH=src python -m retnet_repro smoke --config configs/smoke.json --output-root results/smoke
```

## Paper-scale protocol

```bash
PYTHONPATH=src python -m retnet_repro train --config configs/paper.json --output-root results/runs
```

Requires a large tokenized corpus loader and GPU cluster. Runs with `--steps` are truncated and must not be reported.
