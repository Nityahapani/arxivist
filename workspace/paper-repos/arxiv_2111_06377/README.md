# Masked Autoencoders Are Scalable Vision Learners

**Paper:** Kaiming He, Xinlei Chen, Saining Xie, Yanghao Li, Piotr Dollár, and Ross Girshick (2021), [arXiv:2111.06377](https://arxiv.org/abs/2111.06377).
**Code:** independent PyTorch reproduction written from the paper, with the authors' public [`facebookresearch/mae`](https://github.com/facebookresearch/mae) consulted only for initialisation and position-embedding conventions. This is not the authors' repository and does not claim access to their original run logs or checkpoints.

> **Contribution note.** The scaffold in this directory (model, data pipeline, training/evaluation code, tests, configs, SIR) was generated by an AI assistant and committed under a bot identity so that machine-written work is clearly flagged. Paper-scale experiment runs and results are to be added by the assigned human contributor in their own commits.

## Reproduction status

This repository implements patchify/unpatchify, per-sample random masking (75%), the asymmetric ViT encoder (visible tokens only), the lightweight decoder with shared mask tokens and fixed 2-D sin-cos position embeddings, normalized-pixel loss on masked patches, the AdamW/cosine pretraining loop with MAE augmentation, and a linear probe.

**The paper-scale experiments have not been run here.** The authoring workspace is CPU-only (2 cores, ~1 GB RAM). The unit tests and the smoke configuration verify code paths and invariants, not the paper's empirical claims. Do not report smoke metrics as reproduction results. Paper-scale runs need: multi-node GPU cluster (e.g. 64 × A100) for ViT-L 800-epoch ImageNet pretraining, plus an ImageNet-1K copy.

## What the paper does

MAE splits an image into patches, randomly removes 75% of them, encodes only the visible 25% with a ViT, then a small decoder receives the encoded tokens plus mask tokens at the removed positions and predicts their pixels. Loss is computed only on removed patches against per-patch-normalised pixels. Because the encoder sees only a quarter of the tokens, pretraining is much cheaper; fine-tuned encoders achieve strong ImageNet accuracy and transfer.

## Model and training defaults

- **Mask ratio:** 75%.
- **Decoder:** 8 blocks, width 512, 16 heads.
- **Target:** per-patch normalized pixels.
- **Optimizer:** AdamW (0.9, 0.95), weight decay 0.05, lr = 1.5e-4 × batch/256, cosine with 40 warm-up epochs.
- **Augmentation:** random resized crop (0.2–1.0) + flip only.

## Important assumptions and limits

- Pretraining and linear probe are implemented; full fine-tuning recipe (layer-wise LR decay, RandAug, mixup/cutmix, drop path) is not part of this scaffold.
- Probe on the mean of encoder patch tokens with a feature-standardisation step (stand-in for BatchNorm without affine).
- An ImageNet data loader must be supplied by the contributor (`data.name=imagefolder`).

See [`sir.json`](../../sir-registry/arxiv_2111_06377/sir.json) and the [architecture plan](../../sir-registry/arxiv_2111_06377/architecture_plan_summary.md) for structured assumptions and confidence annotations, and [`comparison/`](comparison/) for the paper-vs-reproduction table.

## Install

Python 3.10+ is required. For CPU-only PyTorch install the CPU wheel first; then install the project and tests:

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install torch --index-url https://download.pytorch.org/whl/cpu
python -m pip install -e '.[test]'
pytest -q
```

For CUDA, install the PyTorch build matching your driver, then `python -m pip install -e '.[test]'`.

## Paper-scale protocol

```bash
PYTHONPATH=src python -m mae_repro train --config configs/paper.json --output-root results/runs
```

Requires an ImageNet-1K loader (`data.name = imagefolder`) and a multi-GPU launcher; the provided loop is single-process. Runs with `--steps` are truncated and must not be reported.
