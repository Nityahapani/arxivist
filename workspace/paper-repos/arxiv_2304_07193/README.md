## Reproduction status

This repository implements the DINOv2 training objective: ViT/14 backbones with LayerScale, stochastic depth, optional SwiGLU, mask token and position-embedding interpolation; untied DINO and iBOT heads; Sinkhorn-Knopp teacher centring; image-level DINO, masked patch-level iBOT and KoLeo losses; multi-crop augmentation; EMA teacher with momentum, weight-decay, LR and teacher-temperature schedules; layer-wise LR decay; and k-NN evaluation.

**The paper-scale experiments have not been run here.** The authoring workspace is CPU-only (2 cores, ~1 GB RAM). The unit tests and the smoke configuration verify code paths and invariants, not the paper's empirical claims. Do not report smoke metrics as reproduction results. Paper-scale runs need: a large A100 cluster for ViT-g/14 on LVD-142M; ViT-S/B experiments on ImageNet need multiple GPUs.

## What the paper does

DINOv2 trains a student ViT to match an EMA teacher at two levels: [CLS] prototype distributions across global and local crops (DINO) and patch prototype distributions at masked positions (iBOT). The teacher outputs are centred with Sinkhorn-Knopp, and a KoLeo term spreads student features within a batch. Scaled to a 1B-parameter ViT on a curated 142M-image dataset, the frozen features transfer to many tasks.

## Model and training defaults

- **Crops:** 2 × 224 (scale 0.32–1) + 8 × 98 (scale 0.05–0.32).
- **Teacher:** Sinkhorn-Knopp (3 iters), temperature 0.04 → 0.07.
- **Losses:** DINO + iBOT + 0.1 · KoLeo.

## Important assumptions and limits

- LR, warmup, prototype counts, head sizes and teacher momentum start in configs/paper.json are best-recalled values; verify against the paper's appendix.
- Random (not block-wise) patch masking with ratio U[0.1, 0.5] on 50% of global crops.
- FlashAttention/xFormers, sequence packing, FSDP and the high-resolution phase are not implemented.
- Synthetic images replace LVD-142M; the curation pipeline is not implemented.

## Install

Python 3.10+ is required. For CPU-only PyTorch install the CPU wheel first; then install the project and tests:

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install torch --index-url https://download.pytorch.org/whl/cpu
python -m pip install -e '.[test]'
pytest -q
```

For CUDA, install the PyTorch build matching your driver, then `python -m pip install -e '.[test]'`.

## Quick smoke test

A deliberately tiny configuration that checks the pipeline end to end; it is **not** a paper result.

```bash
PYTHONPATH=src python -m dinov2_repro smoke --config configs/smoke.json --output-root results/smoke
```

## Paper-scale protocol

```bash
PYTHONPATH=src python -m dinov2_repro train --config configs/paper.json --output-root results/runs
```

Requires a large curated dataset (LVD-142M is not public; ImageNet-22k is a substitute) and a GPU cluster. Runs with `--steps` are truncated and must not be reported.
