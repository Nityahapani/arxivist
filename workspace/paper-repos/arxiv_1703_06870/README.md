# Mask R-CNN

**Paper:** Kaiming He, Georgia Gkioxari, Piotr Dollár, and Ross Girshick (2017), [arXiv:1703.06870](https://arxiv.org/abs/1703.06870).
**Code:** independent PyTorch reproduction written from the paper. This is not the authors' repository and does not claim access to their original run logs or checkpoints.

> **Contribution note.** The scaffold in this directory (model, data pipeline, training/evaluation code, tests, configs, SIR) was generated by an AI assistant and committed under a bot identity so that machine-written work is clearly flagged. Paper-scale experiment runs and results are to be added by the assigned human contributor in their own commits.

## Reproduction status

This repository implements Mask R-CNN in pure PyTorch: ResNet-FPN backbone with frozen BN, FPN-RPN with anchor labelling/sampling and NMS, vectorised bilinear RoIAlign (exact on linear features, sub-pixel sensitive) with FPN level assignment, box head with class-specific regression, the 4-conv mask head with per-class 28×28 sigmoid masks and GT-class-only BCE, mask targets via RoIAlign of GT masks, inference with per-class NMS and mask pasting, and the SGD training recipe. The R-50-FPN model has ~44.4M parameters.

**The paper-scale experiments have not been run here.** The authoring workspace is CPU-only (2 cores, ~1 GB RAM). The unit tests and the smoke configuration verify code paths and invariants, not the paper's empirical claims. Do not report smoke metrics as reproduction results. Paper-scale runs need: 8 GPUs for ~1–2 days (R-50-FPN, 160k iterations) plus COCO 2017.

## What the paper does

Mask R-CNN adds a small FCN mask branch to each RoI of Faster R-CNN, running in parallel with classification and box regression. Pixel-accurate masks require RoIAlign, which samples RoI features by bilinear interpolation instead of quantising RoI boundaries. Masks are predicted per class and supervised only for the ground-truth class with a binary cross-entropy, decoupling mask and class prediction.

## Model and training defaults

- **Heads:** box 2×FC1024 on 7×7 RoIAlign; mask 4×conv256 + deconv on 14×14, 28×28 output.
- **RoIs:** 512/image, 25% positive (IoU ≥ 0.5).
- **Optimizer:** SGD, LR 0.02 (batch 16), momentum 0.9, wd 1e-4, ×0.1 at 120k / 160k.

## Important assumptions and limits

- Default aligned=True (half-pixel offset, later Detectron2 convention); aligned=False reproduces original Detectron.
- Random init in this repo; paper uses ImageNet-pretrained backbones.
- FPN-style RPN (anchor sizes 32–512 on P2–P6, 256 anchors/image, NMS 0.7, 2000/1000 proposals).
- Linear warmup over 500 iterations in paper config (Detectron convention, not in paper).

See [`sir.json`](../../sir-registry/arxiv_1703_06870/sir.json) and the [architecture plan](../../sir-registry/arxiv_1703_06870/architecture_plan_summary.md) for structured assumptions and confidence annotations, and [`comparison/`](comparison/) for the paper-vs-reproduction table.

## Install

Python 3.10+ is required. For CPU-only PyTorch install the CPU wheel first; then install the project and tests:

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install torch --index-url https://download.pytorch.org/whl/cpu
python -m pip install -e '.[test]'
pytest -q
```

For CUDA, install the PyTorch build matching your driver, then `python -m pip install -e '.[test]'`.

## Quick smoke test

A deliberately tiny configuration that checks the pipeline end to end; it is **not** a paper result.

```bash
PYTHONPATH=src python -m mask_rcnn_repro smoke --config configs/smoke.json --output-root results/smoke
```

## Paper-scale protocol

```bash
PYTHONPATH=src python -m mask_rcnn_repro train --config configs/paper.json --output-root results/runs
```

Needs a COCO loader, ImageNet-pretrained backbone and pycocotools (`pip install .[coco]`). Runs with `--steps` are truncated and must not be reported.
