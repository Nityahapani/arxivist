# Theoretically Principled Trade-off between Robustness and Accuracy

**Paper:** Hongyang Zhang, Yaodong Yu, Jiantao Jiao, Eric P. Xing, Laurent El Ghaoui, and Michael I. Jordan (2019), [arXiv:1901.08573](https://arxiv.org/abs/1901.08573).
**Code:** independent PyTorch reproduction written from the paper, with the authors' public [`yaodongyu/TRADES`](https://github.com/yaodongyu/TRADES) consulted only for training-schedule details. This is not the authors' repository and does not claim access to their original run logs or checkpoints.

> **Contribution note.** The scaffold in this directory (model, data pipeline, training/evaluation code, tests, configs, SIR) was generated by an AI assistant and committed under a bot identity so that machine-written work is clearly flagged. Paper-scale experiment runs and results are to be added by the assigned human contributor in their own commits.

## Reproduction status

This repository implements WideResNet (WRN-34-10), the TRADES KL inner maximisation (Algorithm 1), the TRADES loss with β=1/λ, white-box PGD (FGSM^k) evaluation, CIFAR-10 augmentation, and the training loop.

**The paper-scale experiments have not been run here.** The authoring workspace is CPU-only (2 cores, ~1 GB RAM). The unit tests and the smoke configuration verify code paths and invariants, not the paper's empirical claims. Do not report smoke metrics as reproduction results. Paper-scale runs need: one modern GPU (≥16 GB) for ~1-2 days for WRN-34-10 with the 10-step inner loop.

## What the paper does

TRADES bounds robust error by natural error plus a boundary-error term and turns the bound into a training objective: cross-entropy on clean inputs plus β times the KL divergence between predictions on clean and adversarially perturbed inputs, where the perturbation maximises that KL inside an L∞ ball. β controls the accuracy/robustness trade-off.

## Model and training defaults

- **Model:** WRN-34-10.
- **Threat model:** L∞, ε=0.031 (≈8/255).
- **Inner max:** 10 steps, step 0.007, init x+0.001·N(0,I).
- **Optimizer:** SGD momentum 0.9, LR 0.1, weight decay 2e-4, batch 128.
- **β=1/λ:** 6 (also run 1).

## Important assumptions and limits

- Train 76 epochs with LR 0.1 decayed x0.1 at epoch 75, batch 128, weight decay 2e-4.
- PGD-20 on cross-entropy, step 0.003, random uniform start in the eps-ball.
- No normalisation layer; inputs in [0, 1] so eps=0.031 is in pixel units.

See [`sir.json`](../../sir-registry/arxiv_1901_08573/sir.json) and the [architecture plan](../../sir-registry/arxiv_1901_08573/architecture_plan_summary.md) for structured assumptions and confidence annotations, and [`comparison/`](comparison/) for the paper-vs-reproduction table.

## Install

Python 3.10+ is required. For CPU-only PyTorch install the CPU wheel first; then install the project and tests:

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install torch --index-url https://download.pytorch.org/whl/cpu
python -m pip install -e '.[test]'
pytest -q
```

For CUDA, install the PyTorch build matching your driver, then `python -m pip install -e '.[test]'`.

For CIFAR-10 also install `python -m pip install -e '.[vision]'`.

## Quick smoke test

A deliberately tiny configuration that checks the pipeline end to end; it is **not** a paper result.

```bash
PYTHONPATH=src python -m trades_repro smoke --config configs/smoke.json --output-root results/smoke
```

## Paper-scale protocol

```bash
PYTHONPATH=src python -m trades_repro train --config configs/paper.json --output-root results/runs
```

Set `train.beta` to 1.0 or 6.0 for the two Table 5 rows. Runs with `--steps` are truncated and must not be reported as paper results.
