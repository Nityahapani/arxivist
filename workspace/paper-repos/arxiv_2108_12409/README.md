# Train Short, Test Long: Attention with Linear Biases Enables Input Length Extrapolation

**Paper:** Ofir Press, Noah A. Smith, and Mike Lewis (2021), [arXiv:2108.12409](https://arxiv.org/abs/2108.12409).
**Code:** independent PyTorch reproduction written from the paper, with the authors' public [`ofirpress/attention_with_linear_biases`](https://github.com/ofirpress/attention_with_linear_biases) consulted only for the non-power-of-two slope rule. This is not the authors' repository and does not claim access to their original run logs or checkpoints.

> **Contribution note.** The scaffold in this directory (model, data pipeline, training/evaluation code, tests, configs, SIR) was generated by an AI assistant and committed under a bot identity so that machine-written work is clearly flagged. Paper-scale experiment runs and results are to be added by the assigned human contributor in their own commits.

## Reproduction status

This repository implements ALiBi biases (including the non-power-of-two slope rule), a causal Transformer LM with interchangeable ALiBi / sinusoidal / rotary / learned positions, non-overlapping and sliding-window perplexity evaluation at lengths beyond training, and the train-short/test-long protocol.

**The paper-scale experiments have not been run here.** The authoring workspace is CPU-only (2 cores, ~1 GB RAM). The unit tests and the smoke configuration verify code paths and invariants, not the paper's empirical claims. Do not report smoke metrics as reproduction results. Paper-scale runs need: 8 GPUs × ~1–2 days per training length for the 16-layer WikiText-103 model.

## What the paper does

ALiBi drops position embeddings entirely. Each attention head adds −m·(i−j) to the score between query i and key j, with fixed slopes m forming a geometric sequence across heads. Because this penalty is defined for any distance, a model trained on short sequences can be evaluated on much longer ones. The paper compares extrapolation of sinusoidal, rotary, T5-bias and ALiBi models on WikiText-103 and larger corpora.

## Model and training defaults

- **Model:** 16 layers, d=1024, 8 heads, FFN 4096, dropout 0.3 (non-adaptive embeddings).
- **ALiBi slopes (8 heads):** 1/2, 1/4, …, 1/256.
- **Protocol:** train at L_train, evaluate at L_valid ∈ {L, 2L, …}.

## Important assumptions and limits

- Use standard tied embeddings instead of adaptive input / adaptive softmax.
- Adam (0.9, 0.98), LR 1e-4 with warmup, clip 0.1, 286k updates.
- Use the interleaving rule from the reference implementation for head counts that are not powers of two.

See [`sir.json`](../../sir-registry/arxiv_2108_12409/sir.json) and the [architecture plan](../../sir-registry/arxiv_2108_12409/architecture_plan_summary.md) for structured assumptions and confidence annotations, and [`comparison/`](comparison/) for the paper-vs-reproduction table.

## Install

Python 3.10+ is required. For CPU-only PyTorch install the CPU wheel first; then install the project and tests:

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install torch --index-url https://download.pytorch.org/whl/cpu
python -m pip install -e '.[test]'
pytest -q
```

For CUDA, install the PyTorch build matching your driver, then `python -m pip install -e '.[test]'`.

For WikiText-103 also install `python -m pip install -e '.[hf]'`.

```bash
PYTHONPATH=src python -m alibi_repro smoke --config configs/smoke.json --output-root results/smoke
```

## Paper-scale protocol

```bash
PYTHONPATH=src python -m alibi_repro train --config configs/paper.json --output-root results/runs
```

Each entry in `model.positions` is trained separately with the same data and seed, then evaluated at every length in `eval.lengths`. Runs with `--steps` are truncated and must not be reported.
