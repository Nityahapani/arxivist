# FlashAttention: Fast and Memory-Efficient Exact Attention with IO-Awareness

**Paper:** Tri Dao, Daniel Y. Fu, Stefano Ermon, Atri Rudra, and Christopher Ré (2022), [arXiv:2205.14135](https://arxiv.org/abs/2205.14135).
**Code:** independent PyTorch reproduction written from the paper. This is not the authors' repository and does not claim access to their original run logs or checkpoints.

> **Contribution note.** The scaffold in this directory (model, data pipeline, training/evaluation code, tests, configs, SIR) was generated by an AI assistant and committed under a bot identity so that machine-written work is clearly flagged. Paper-scale experiment runs and results are to be added by the assigned human contributor in their own commits.

## Reproduction status

This repository implements the tiled FlashAttention forward pass with online softmax and saved log-sum-exp, the recomputation-based backward pass, an autograd Function with O(N) extra memory, causal masking with early block exit, block-sparse FlashAttention, and an analytical HBM-access model. Forward, log-sum-exp, and gradients match standard attention exactly in float64.

**The paper-scale experiments have not been run here.** The authoring workspace is CPU-only (2 cores, ~1 GB RAM). The unit tests and the smoke configuration verify code paths and invariants, not the paper's empirical claims. Do not report smoke metrics as reproduction results. Paper-scale runs need: A100 GPUs and the CUDA kernel for speed measurements; the reference runs on CPU.

## What the paper does

FlashAttention reorganises attention so each block of queries is processed against blocks of keys and values in fast on-chip memory, maintaining running maxima and normalisers to combine partial softmaxes exactly. The backward pass recomputes block attention probabilities from the saved log-sum-exp instead of storing the N×N matrix, trading FLOPs for far fewer HBM accesses.

## Model and training defaults

- **Block sizes:** B_c = ⌈M/4d⌉, B_r = min(B_c, d).
- **Softmax scale:** d^(-1/2).

## Important assumptions and limits

- Pure-PyTorch tiled implementation for correctness and IO accounting; no CUDA kernel.
- Attention dropout (regenerated from the RNG state in the backward pass) is not implemented.
- Element counts per (batch, head) for Algorithm 0 and Algorithm 1 with the Algorithm 2 loop order.

See [`sir.json`](../../sir-registry/arxiv_2205_14135/sir.json) and the [architecture plan](../../sir-registry/arxiv_2205_14135/architecture_plan_summary.md) for structured assumptions and confidence annotations, and [`comparison/`](comparison/) for the paper-vs-reproduction table.

## Install

Python 3.10+ is required. For CPU-only PyTorch install the CPU wheel first; then install the project and tests:

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install torch --index-url https://download.pytorch.org/whl/cpu
python -m pip install -e '.[test]'
pytest -q
```

For CUDA, install the PyTorch build matching your driver, then `python -m pip install -e '.[test]'`.

## Paper-scale protocol

```bash
PYTHONPATH=src python -m flashattention_repro train --config configs/paper.json --output-root results/runs
```

Reproducing speed and long-context results needs the CUDA kernel (`pip install .[cuda]`) and A100-class GPUs. Runs with `--steps` are truncated and must not be reported.
