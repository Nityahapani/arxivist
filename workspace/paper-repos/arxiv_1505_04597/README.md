# U-Net: Convolutional Networks for Biomedical Image Segmentation

**Paper:** Olaf Ronneberger, Philipp Fischer, and Thomas Brox (2015), [arXiv:1505.04597](https://arxiv.org/abs/1505.04597).
**Code:** independent PyTorch reproduction written from the paper. This is not the authors' repository and does not claim access to their original run logs or checkpoints.

> **Contribution note.** The scaffold in this directory (model, data pipeline, training/evaluation code, tests, configs, SIR) was generated by an AI assistant and committed under a bot identity so that machine-written work is clearly flagged. Paper-scale experiment runs and results are to be added by the assigned human contributor in their own commits.

## Reproduction status

This repository implements the original unpadded U-Net (572→388), He-style Gaussian initialisation, the weighted pixel-wise cross-entropy with the Eq. 2 separation-border weight map, elastic deformation augmentation, and overlap-tile inference with mirror padding. A synthetic touching-cell generator drives the smoke test.

**The paper-scale experiments have not been run here.** The authoring workspace is CPU-only (2 cores, ~1 GB RAM). The unit tests and the smoke configuration verify code paths and invariants, not the paper's empirical claims. Do not report smoke metrics as reproduction results. Paper-scale runs need: a single GPU with ≥6 GB memory (the paper used a 6 GB Titan for ~10 hours).

## What the paper does

U-Net pairs a contracting path of 3×3 valid convolutions and max-pooling with an expansive path of 2×2 up-convolutions and concatenations of cropped encoder features, followed by a 1×1 classifier. Training uses large tiles with batch size 1 and high momentum, strong elastic deformations, and a loss weight map that emphasises thin background borders between touching cells.

## Model and training defaults

- **Model:** depth 4, base 64 channels, dropout 0.5, valid convolutions.
- **Loss:** weighted CE with w0=10, σ=5.
- **Optimizer:** SGD momentum 0.99, batch 1, 572×572 tiles.

## Important assumptions and limits

- LR 0.01 and 10k iterations.
- The border term is applied to background pixels between cells.
- Coarse 3x3 displacement field upsampled with cubic spline zoom (scipy).
- Synthetic touching disks replace EM/cell data for CI.

See [`sir.json`](../../sir-registry/arxiv_1505_04597/sir.json) and the [architecture plan](../../sir-registry/arxiv_1505_04597/architecture_plan_summary.md) for structured assumptions and confidence annotations, and [`comparison/`](comparison/) for the paper-vs-reproduction table.

## Install

Python 3.10+ is required. For CPU-only PyTorch install the CPU wheel first; then install the project and tests:

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install torch --index-url https://download.pytorch.org/whl/cpu
python -m pip install -e '.[test]'
pytest -q
```

For CUDA, install the PyTorch build matching your driver, then `python -m pip install -e '.[test]'`.

## Quick smoke test

A deliberately tiny configuration that checks the pipeline end to end; it is **not** a paper result.

```bash
PYTHONPATH=src python -m unet_repro smoke --config configs/smoke.json --output-root results/smoke
```

## Paper-scale protocol

```bash
PYTHONPATH=src python -m unet_repro train --config configs/paper.json --output-root results/runs
```

Plug the ISBI 2012 EM or cell-tracking loader into `train.run`. Challenge metrics are computed by the organisers' evaluation servers. Runs with `--steps` are truncated and must not be reported.
