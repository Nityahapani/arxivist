# RoFormer: Enhanced Transformer with Rotary Position Embedding

**Paper:** Jianlin Su, Yu Lu, Shengfeng Pan, Ahmed Murtadha, Bo Wen, and Yunfeng Liu (2021), [arXiv:2104.09864](https://arxiv.org/abs/2104.09864).
**Code:** independent PyTorch reproduction written from the paper. This is not the authors' repository and does not claim access to their original run logs or checkpoints.

> **Contribution note.** The scaffold in this directory (model, data pipeline, training/evaluation code, tests, configs, SIR) was generated by an AI assistant and committed under a bot identity so that machine-written work is clearly flagged. Paper-scale experiment runs and results are to be added by the assigned human contributor in their own commits.

## Reproduction status

This repository implements RoPE in three equivalent forms (block-diagonal matrix, complex multiplication, efficient element-wise), the long-term decay bound, RoPE-equipped softmax and linear attention, a BERT-style RoFormer encoder with interchangeable position methods, and an MLM comparison of RoPE vs sinusoidal positions on synthetic data where relative position is what matters.

**The paper-scale experiments have not been run here.** The authoring workspace is CPU-only (2 cores, ~1 GB RAM). The unit tests and the smoke configuration verify code paths and invariants, not the paper's empirical claims. Do not report smoke metrics as reproduction results. Paper-scale runs need: several GPUs for BERT-base-scale MLM pretraining; the synthetic comparison runs on CPU.

## What the paper does

RoPE multiplies each two-dimensional slice of the query and key by a rotation whose angle grows linearly with position, at frequency θ_i = 10000^(−2(i−1)/d). The dot product of a rotated query and key then depends only on their relative offset, while the representation itself still encodes absolute position. No position embeddings are added to the token stream.

## Model and training defaults

- **θ base:** 10000.
- **Encoder:** post-LN, GELU FFN, no position embeddings.

## Important assumptions and limits

- No numeric targets are hard-coded; read targets from Table 2 (GLUE), Table 5 (CAIL2019-SCM) and Figures 3–4 (pretraining curves).
- Interleaved pairs (x_{2i-1}, x_{2i}) as in Eq. 15.
- phi = elu + 1 for both queries and keys.
- AdamW, LR 1e-4, 10k warmup in configs/paper.json.

See [`sir.json`](../../sir-registry/arxiv_2104_09864/sir.json) and the [architecture plan](../../sir-registry/arxiv_2104_09864/architecture_plan_summary.md) for structured assumptions and confidence annotations, and [`comparison/`](comparison/) for the paper-vs-reproduction table.

## Install

Python 3.10+ is required. For CPU-only PyTorch install the CPU wheel first; then install the project and tests:

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install torch --index-url https://download.pytorch.org/whl/cpu
python -m pip install -e '.[test]'
pytest -q
```

For CUDA, install the PyTorch build matching your driver, then `python -m pip install -e '.[test]'`.

## Quick smoke test

A deliberately tiny configuration that checks the pipeline end to end; it is **not** a paper result.

```bash
PYTHONPATH=src python -m roformer_repro smoke --config configs/smoke.json --output-root results/smoke
```

## Paper-scale protocol

```bash
PYTHONPATH=src python -m roformer_repro train --config configs/paper.json --output-root results/runs
```

Real-corpus MLM pretraining, GLUE fine-tuning, Enwik8 and CAIL2019-SCM need external data loaders. Runs with `--steps` are truncated and must not be reported.
